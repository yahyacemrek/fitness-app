# FitTakip 💪

Kişisel fitness takip uygulaması: antrenman programı ve kayıtları, kilo takibi, kalori hedefi ve haftalık beslenme programı.

- React + Vite, veriler tarayıcıda (localStorage) saklanır.
- `main` dalına her push'ta GitHub Actions ile GitHub Pages'e otomatik yayınlanır.

## Yerel çalıştırma
```bash
npm install
npm run dev
```
